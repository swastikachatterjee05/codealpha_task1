# codealpha_ecommerce-

VELORA – E-Commerce Store

VELORA is a modern e-commerce web application for browsing and purchasing tech accessories and electronic products. The application provides a clean shopping experience with product listings, detailed product pages, user authentication, and cart management.


✨ Project Features

- Product catalog for electronic devices and tech accessories
- Product details and individual product pages
- Shopping cart with add/remove functionality
- Dynamic cart count and price calculation
- User registration and login system
- Authenticated user profile
- Checkout workflow
- Responsive and intuitive user interface
- Clean and modern UI design
- Seamless navigation across the application


🎯 Project Purpose

The primary goal of VELORA is to showcase a full-stack web development workflow using pure JavaScript, CSS, HTML, and Node.js without relying on complex frontend frameworks. 

- Backend API Integration: Serves static assets and provides REST API endpoints for product data and order submission.
- Single-Page Dynamics: Handles view navigation, cart state updates, and checkout flows without full page reloads.
- Localized Experience: Integrates currency formatting in Indian Rupee (`₹`) across catalog items, product cards, and cart totals.


🛠️ Built With

- Frontend: HTML5, CSS3, Vanilla JavaScript (ES6+)
- Backend: Node.js, Express.js
- Currency: Localized to Indian Rupee (`en-IN`)
